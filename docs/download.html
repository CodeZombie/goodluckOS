goodluckOS Hardware Identifier

This tool will identify which hardware variant you have and, if supported, will provide you with the correct download link for goodluckOS.

If your device is not supported, PLEASE do not download a random release and try to boot it. It will almost certainly fail and, while unlikely, could damage your hardware.

Q: How do I use this?

  1. Dump your stock SD card (the one that came with your device) to a file.
  2. Drop that sd card dump file onto this page.
  3. The page will extract the hardware configuration file (script.bin) and compare it to a list of suported hardware profiles.
  4. If it finds a match, it'll show you a download link
  5. If no match is found, it'll provide you with a download link for the script.bin file. Please create an Issue on Github with information about your device, and upload the provided script.bin file. We can use this to build a version of goodluckOS for your device.

Q: How do I create an image of my stock microSD card?

  • If you're using windows, use win32diskimager.
  • If you use Linux, find the device file for your microSD card with lsblk and then run dd if=/dev/sdX of=stock_sdcard.img bs=1M count=128 status=progress, where /dev/sdX is your specific device file.
