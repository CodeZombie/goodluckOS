Step 1: Load your SD Card Image help

For this step, you'll need an image of the stock microSD card that came with your GA36-MB. You only need the first 128mb, but if the image is larger that's fine.

Windows Guide

Plug the microSD card into your PC with an adapter and create an image with HDD Raw Copy Tool v1.20

Linux Guide

  1. Plug your microSD card into your computer
  2. Run lsblk to find the path to your device file. It'll look like /dev/sdx
  3. Run dd if=/dev/sdx of=stock_sdcard.img bs=1M count=128 status=progress, where /dev/sdx is the path you found in the previous step.

Step 2: Prepare Base Image help

In this step, you'll download the goodluckOS base image zip archive, unzip it, and load the file back into this tool.

You can download this file from https://github.com/CodeZombie/goodluckOS/releases or use the Download button below.

Be sure you download the correct version for your hardware. A33 builds are NOT compatible with A23 hardware and vice versa.
