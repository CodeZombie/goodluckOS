How To Use goodluckOS
    Welcome to goodluckOS!

Button Shortcuts
    START + SELECT      : Gracefully close running application
    START + SELECT + FN : Kill running application
    FN + VOL UP/DOWN    : Adjust screen brightness
    FN + UP             : Show CPU/GPU stat graph
    FN + DOWN           : Toggle audio output (Speaker or Headphones)
    POWER               : Toggle the screen

Gallery
    LEFT / RIGHT        : Screenshots or Recordings (on the tabs)
    A                   : Open full screen (recordings play), A or B closes it
    X                   : Delete the selected file
    B                   : Back to the tabs, then close the Gallery
